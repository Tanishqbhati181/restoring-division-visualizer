# Restoring Division Visualizer

An interactive web-based visualization of the **Restoring Division Algorithm** that demonstrates binary division step by step.

🌐 **Live Demo:** https://restoringdivision.netlify.app/

## About the Project

This project helps students understand how the Restoring Division Algorithm works through interactive binary register visualization and step-by-step execution.

## Features

- Enter custom dividend and divisor values.
- Visualize A, Q and M registers in binary.
- Step-by-step algorithm execution.
- Next Step and Back controls.
- Auto-play animation.
- Iteration log and final result.
- Quotient and remainder calculation.
- Multiple predefined examples.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
